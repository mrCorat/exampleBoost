**Исследуемый механизм**: Паттерн Visitor в алгоритмах обхода и система Property Maps для внешнего хранения данных вершин.

## Описание
Проект демонстрирует, как алгоритм `depth_first_search` инвертирует управление, передавая его пользовательскому визитору (`route_printer_visitor`) в ключевые моменты обхода. Визитор использует механизм `property_map` для получения доступа к данным вершины (имени города), не нарушая инкапсуляции структуры графа.
